# Latin Modern Roman

The resume is typeset in [Latin Modern Roman](https://www.gust.org.pl/projects/e-foundry/latin-modern),
a contemporary revival of Donald Knuth's Computer Modern created by GUST.

The files in this directory are WOFF2 subsets of the Latin Modern webfonts
distributed by the [lmweb](https://github.com/lalten/lmweb) project.
