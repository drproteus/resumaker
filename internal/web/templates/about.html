Help & about

Resumaker keeps a few versions of your resume, lets you edit them as a structured form, and prints a clean one-page PDF from the browser.

Build a resume

  1. Create a resume and pick a style.
  2. Fill in contact details, experience, education and skills.
  3. Save, then open Preview & print to check the layout.
  4. Print with the button or Ctrl/⌘+P, and choose Save as PDF.

Editor tips

  • Drag the handle beside a row to reorder contact details, experience, education or skill groups. With a handle focused, the ↑ and ↓ keys move that row.
  • Add and remove rows freely. Empty rows are ignored when you save.
  • Put each experience highlight or education detail on its own line.
  • Separate skills with commas; separate keyword tags with commas too.
  • Use Duplicate on the resumes list to make a variant without retyping it.

Printing

The preview is a self-contained HTML page. Page size is US Letter, and the print stylesheet handles margins and page breaks. In Chrome or Edge, enable Background graphics if you want the coloured styles to keep their accents.

Privacy

Resume content is encrypted at rest with AES-256-GCM. Each account has its own data key, wrapped by the server's master key; the plaintext only exists in memory while a request needs it.

Sign-in is handled by GitHub or Google OAuth. Accounts are keyed by the provider's user ID, never linked by email address, so your resume is only visible to the identity that created it.

Open source

Resumaker is a small Go project. The templates, print styles and encryption code are all in the repository, and the bundled fonts are licensed for redistribution.
